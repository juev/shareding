ShareDing sends links from Android's Share menu to your own linkding server. It stores each link in a local queue before sending, so you can keep browsing when the server is offline or available only through a LAN or VPN.

Features:
* Share HTTP and HTTPS links without opening the main app screen.
* Add a URL, title, description, and tags manually.
* Keep pending bookmarks across app restarts and device reboots.
* Retry in the background when a network becomes available or a server error occurs.
* Review and retry queued bookmarks; remove entries with confirmation.
* Set default tags and bookmark options, with tag suggestions from linkding.

Network connections:
* ShareDing sends bookmarks to your linkding server.
* When a queued link comes from a known URL shortener such as t.co, bit.ly, or vk.cc, background sync asks the shortener where the link leads and sends that address to linkding.
* If you tap Fetch page details in the Add Bookmark form, ShareDing requests the bookmarked page from your device to read its title and description.
The shortener and page requests do not include your linkding API token.

ShareDing requires Android 10 or newer and your own linkding server. Enter its HTTPS URL and API token in Settings. To reach a server through another route, use a VPN on your device.
